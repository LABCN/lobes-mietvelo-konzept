# Lobes Bikes – Kindervelo-Abo (Designkonzept)

Statisches UX-Mockup, nur zur Ansicht. Alle Knöpfe, CTAs und Formulare sind bewusst ohne Funktion:
kein Warenkorb, kein Checkout, kein Abo-Abschluss, keine Formularübermittlung, keine Tracking-Skripte.

Illustrationen: eigene SVGs (assets/), Schriften: Fraunces & Instrument Sans (Google Fonts).
